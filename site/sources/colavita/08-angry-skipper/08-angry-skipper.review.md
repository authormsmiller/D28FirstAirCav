`locations/fsb-rita` already carries an unreconciled detail this chapter reinforces rather than resolves: Larry Hackett's account (quoted in Colavita's book, same passage as the existing tribute document) says 2/8 Cav took over Rita on **9 November** from a 1st ID garrison "overrun the night before." The page's own occupancy table uses the ORLL's **7 November** date, and the well-documented 1st ID battle (Rogers MOH) was **1 November** — six to eight days before either takeover date, not "the night before." This chapter doesn't add a new discrepancy, just confirms the existing one traces back to Hackett's own account (now doubly sourced, since Colavita's book quotes the same tribute) rather than a one-off transcription slip. Still worth a line on the FSB Rita open-questions list if it isn't already framed that way.
