# Operation Happy Valley (13–31 October 1965) — reference only, NO published page

This folder holds the source PDF for **Operation Happy Valley** but there is **no published event
page**, by design.

**Why no page:** Happy Valley (13–31 Oct 1965) was an An Khe TAOR clearing-and-pacification
operation. The MACV Lessons-Learned study (No. 58) names **1st Battalion, 5th Cavalry (1/5 Cav)** as
the unit that participated in all phases, with two brigades committed only in the first
(domination) phase. **2/8 Cavalry is not named.** By late October 1965, 2/8 Cav was moving to the
**Plei Me relief / Pleiku Campaign** (its firebase positions from ~24 Oct — Ps Cherry, FB
Homecoming "Siege of Plei Me," FB South — are all Plei Me-related, and the battalion's documented
action is Operation All the Way, 27 Oct – 9 Nov).

**Conclusion:** SGT Paul Malec and D/2-8 Cav were almost certainly **not** in Happy Valley; it ran
concurrently with their move to the Pleiku Campaign. Filed here for reference and to record the
disambiguation, not as part of Malec's trail. Revisit only if a primary source places 2/8 Cav in
the An Khe TAOR operation in mid-to-late October 1965.

**Source:** `Lesson_Learned_58_Optn_Happy_Valley_Oct_65-OCR.pdf` — MACV Counterinsurgency Lessons
Learned No. 58, Operation Happy Valley, dated 20 June 1966.
