# Sources — Operation Jim Bowie (March 1966)

Operation Jim Bowie, 7–28 March 66.

- Catalogued at WorldCat **OCLC 32947205**.
- Retrieve from **NARA RG 472** (1st Cav Div after-action reports) or the **Donovan Research
  Library** (Fort Benning / MCoE). Paid-research option: Golden Arrow Research.
- When obtained, drop the PDF here and cite it in `index.md` sources.

**Also useful for the 21 March action:** the **2/8 Cav daily staff journal** (NARA RG 472) — the
day-of record that would pin Malec's wounding.

**Filed here:**
- `MACV-Communique-080-66-21Mar1966.pdf` — official MACV daily communiqué #080-66, 1700H
  21 Mar 1966 (Malec's wounding date). Item 11 (Binh Dinh) reports Operation Jim Bowie: "no
  significant contact in the nine days of searching"; friendly casualties "majority sustained from
  punji sticks." Same-day primary source. (Source PDF added by Michael; OCR text extractable.)
  Stable URL: https://vva.vietnam.ttu.edu/images.php?img=/images/213/2130619006.pdf
  (Texas Tech Virtual Vietnam Archive, item 2130619006).
