# Stub Candidates — Cross-Source Tracker

**Purpose:** a single running list of named people who have surfaced in research (any source —
memoirs, ORLLs, photo collections, oral histories) but do not yet have a `site/soldiers/` profile.
Before this tracker existed, candidates only lived inside whichever chapter/document review
turned them up (see `sources/colavita/08-angry-skipper/08-angry-skipper.review.md` for the first
instance) — easy to lose track of once a session ends. This file is the durable, cross-source
home for that list, independent of which source or session first raised a name.

**Process (per the Session 101 standing rule):** a name lands here when a source names someone
with no existing profile. It does **not** get built automatically — building a profile is always
Michael's call, prompted by a photo, a name check ("do we have folders for X and Y"), or an
explicit go-ahead. Once built, move the row from **Pending** to **Resolved** with the date and the
resulting slug.

**Columns:**
- **Name** — fullest form known, with nicknames in quotes.
- **Rank / Role** — as given in the source.
- **Unit** — down to platoon if known.
- **Data known** — a compressed summary of what the source actually says about them.
- **Source** — path to the digest/document/review that generated the candidate.
- **Status** — `candidate` (pending) or a resolution (`built: <slug>`, `out of scope`, `merged
  into existing: <slug>`).

Last updated: 2026-07-27
