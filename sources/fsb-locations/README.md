# FSB-locations — provenance & usage

**Source file:** `FSB-locations.pdf` (held in this folder) — a **553-page firebase / LZ gazetteer**
for Vietnam. Each entry gives a site name and type (FB, LZ, OP, Ps…), **decimal latitude/longitude**,
an **MGRS grid** (e.g., `YS803953`), the **1:50,000 map sheet** (e.g., `6530-4`), a **note** (occupying
unit + dates + namesake / operation), and **citation codes** (numbered references and DTIC `AD…` report
numbers). The structure is consistent with the standard published "Where We Were in Vietnam"–style
gazetteer; treat the specific authorship as to-be-confirmed.

**Why we keep the whole file:** it lets us **reliably pin firebases to a map** (lat/long + MGRS) and
attach dated unit occupancy to each site. Preserved here in full for lookup as the archive grows.

**Derived list:** [`2-8-cav-fsb-list.md`](2-8-cav-fsb-list.md) — every entry whose note names **2/8th Cav**
(204 entries; "2/8th **Inf**" excluded as a different regiment).

## Fanning vs. Fontaine — resolved (different firebases, different grids)

| Site | Grid | Lat / Long | 2/8 Cav note |
|------|------|-----------|--------------|
| **FB Fontaine** | YS803953 | 10.8053, 107.5595 | 2/8th Cav from 28 Jan 71; closed 8 May 71. Named for **Michael A. Fontaine** (DSC, KIA 10 Jan 69). |
| **FB Fanning** | YS751995 (also YS759987) | 10.8436, 107.5123 | 2/8th Cav 8 May–20 Aug 71; Op Overlord. Named for **Martin V. Fanning** (KIA 24 Apr 71). |

They are roughly 5 km apart — distinct bases, not the same place under two names.

gazetteer lists each known position. Use the grid that matches the date in question.

## ⚠ FB Mace — watch for a false match

The gazetteer lists **several "FB Mace" entries at different grids**. Marvin's Mace (his arrival
base, ~15 Dec 70) is the **III Corps / Long Khanh one near Gia Ray** — grid ≈ **YT627111**
(10.949, 107.400), noted "aka FSB Blackhorse / Wisehart," held by the 199th LIB and 1st ACD units
(2/5 Cav Sep 71, 1/7 Cav CP Oct 71). 2/8 Cav is not separately named at Mace in this reference,
but D Co 2/8 was there per Marvin's letters. **Do not** use the "FB Mace" at **XS065613**
(10.51, 105.97) — that is a different firebase in the **Mekong Delta (IV Corps)**, unrelated to
the 1st Cav. Always match the grid to the III Corps / Long Khanh area for our Mace.
